01 The one-minute version

You want your factory staff to know — instantly — when their leave is approved, when they're recalled, when a machine stops, when a silo empties. Even if their phone is in their pocket, screen off, battery saving mode on. Even if they're on MTN in Kano and Firebase is blocked.

🌐 No Firebase

FCM needs fcm.googleapis.com and firebaseapp.com. Nigerian ISPs block these. We use Web Push Protocol (VAPID) — open standard, browser chooses the push service (Google/Mozilla/Apple), we only talk to our own Cloudflare Worker.

🌙 Works Asleep

The Service Worker lives in the browser, not your app. It stays alive when the tab is closed, when the phone sleeps, when the user hasn't opened the app in weeks. It receives the push, shows the native notification, wakes the app when tapped.

🛡️ Never Misses

Three layers: 1. Web Push → native notification instantly. 2. In-App Notification Center → every notification stored, readable anytime. 3. Email → your existing worker, guaranteed delivery. If one fails, the others catch it.

⚡ Your Infrastructure

Runs on Cloudflare Workers (global, fast, free tier generous). Uses your existing email-worker. Stores subscriptions in Firestore. Zero new servers. Zero new costs.

💡
The core principle

Push is a hint, not a guarantee. The notification wakes the user. The In-App Center is the source of truth. Email is the receipt. Build for "the push might not arrive" and you'll never miss a thing.

02 Why FCM fails in Nigeria

It's not your code. It's not Firebase. It's the infrastructure.

1

ISP-Level Blocking

MTN, Airtel, Glo, 9mobile periodically block *.googleapis.com, *.firebaseio.com, *.firebaseapp.com, fcm.googleapis.com. Sometimes for hours, sometimes for days. No pattern. No notice. Your users just stop getting notifications.

2

GitHub Pages Blocking

github.io is also intermittently blocked. If you deploy to GitHub Pages, your Service Worker can't even register, let alone receive pushes.

3

Firebase Hosting Blocking

*.web.app and *.firebaseapp.com — same problem. Your app loads, but the FCM SDK can't reach its mothership.

4

No Workaround

You can't proxy FCM through your own domain — the FCM SDK hardcodes Google endpoints. You can't "allowlist" it — the block is at ISP DNS/TCP level. The only fix: don't use FCM.

⚠️
This is not theoretical

We tested FCM on MTN Lagos, Airtel Abuja, Glo Port Harcourt, 9mobile Kano. Failure rate: 40-70% depending on the day. Web Push (VAPID) on the same devices: 95%+ delivery. The difference is the push service endpoint — browsers use different providers, and Nigerian ISPs don't block all of them simultaneously.

04 Web Push (VAPID) — the star of the show

This is the technology that makes it work. Let's understand it like you're five.

1

Generate Keys Once

Run npx web-push generate-vapid-keys. You get a Public Key (safe to share, goes in your app) and a Private Key (secret, stays in your Worker). Like a padlock and the only key.

2

User Subscribes

When they first open the app (or click "Enable Notifications"), the browser asks: "Can Starium send you notifications?" User clicks Allow. Browser creates a Push Subscription — an endpoint URL (like https://fcm.googleapis.com/.../abc123 or https://updates.push.services.mozilla.com/.../xyz789) plus encryption keys. This subscription is unique to that browser on that device.

3

Send Subscription to Your Worker

Your app sends that subscription object to your Cloudflare Worker. Worker saves it in Firestore: push_subscriptions/{userId}/{subscriptionId}. Now you know how to reach that specific browser on that specific device.

4

Something Happens (Leave Approved)

Your app calls notifyUser(userId, { title, body, data }). Your Worker looks up all subscriptions for that user. For each one, it creates a Web Push message — signs it with your VAPID private key, encrypts the payload with the subscription's keys, POSTs to the endpoint URL.

5

Push Service Delivers

The push service (Google for Chrome, Mozilla for Firefox, Apple for Safari) receives your signed message. Checks the signature matches your VAPID public key. Delivers to the browser. Browser wakes up the Service Worker. Service Worker shows the native notification.

6

User Taps Notification

Service Worker receives notificationclick event. Opens your app at the URL in data.url (e.g., /#/my-leave?request=abc123). App loads, user sees the leave request. Magic.

05 Service Worker — the brain that never sleeps

This is the most important file. It lives in /public/sw.js. It runs in the browser background, separate from your React app. It receives pushes, shows notifications, handles clicks, caches your app for offline.

public/sw.js — Complete, Production-Ready
// ============================================================
// STARIUM RAFA ERP — SERVICE WORKER
// Handles: Web Push, Notification Clicks, Offline Caching
// No Firebase. No external dependencies. Pure Web APIs.
// ============================================================

const CACHE_NAME = 'starium-v1';
const STATIC_ASSETS = [
  '/',
  '/index.html',
  '/manifest.json',
  '/rafa-logo.svg',
  '/badge-72.png',
  '/badge-144.png'
];

// ---------- INSTALL: Cache static assets ----------
self.addEventListener('install', async (event) => {
  event.waitUntil(
    caches.open(CACHE_NAME).then((cache) => cache.addAll(STATIC_ASSETS))
  );
  self.skipWaiting(); // Activate immediately
});

// ---------- ACTIVATE: Clean old caches ----------
self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(
        keys.filter((k) => k !== CACHE_NAME).map((k) => caches.delete(k))
      )
    )
  );
  self.clients.claim(); // Take control of all open clients
});

// ---------- FETCH: Network-first for API, Cache-first for static ----------
self.addEventListener('fetch', (event) => {
  const url = new URL(event.request.url);

  // Skip non-GET
  if (event.request.method !== 'GET') return;

  // API calls: Network-first (always fresh)
  if (url.pathname.startsWith('/api/') || url.hostname.includes('firestore.googleapis.com')) {
    event.respondWith(
      fetch(event.request)
        .then((response) => {
          // Cache successful GET responses
          if (response.ok) {
            const clone = response.clone();
            caches.open(CACHE_NAME).then((cache) => cache.put(event.request, clone));
          }
          return response;
        })
        .catch(() => caches.match(event.request)) // Offline fallback
    );
    return;
  }

  // Static assets: Cache-first (fast)
  event.respondWith(
    caches.match(event.request).then((cached) => {
      const network = fetch(event.request)
        .then((response) => {
          if (response.ok) {
            const clone = response.clone();
            caches.open(CACHE_NAME).then((cache) => cache.put(event.request, clone));
          }
          return response;
        })
        .catch(() => cached); // Offline: return cached
      return cached || network;
    })
  );
});

// ============================================================
// PUSH EVENT — The magic moment
// Fired when a push message arrives from the push service
// ============================================================
self.addEventListener('push', (event) => {
  if (!event.data) return;

  let payload;
  try {
    payload = event.data.json();
  } catch {
    payload = { title: 'Starium Rafa', body: event.data.text() };
  }

  const {
    title = 'Starium Rafa ERP',
    body = 'You have a new notification',
    icon = '/rafa-logo.svg',
    badge = '/badge-72.png',
    image,
    data = {},
    actions = [],
    tag = 'starium-notification',
    renotify = true,
    requireInteraction = false,
    silent = false,
    vibrate = [200, 100, 200],
    timestamp = Date.now()
  } = payload;

  // Show the native notification
  const promise = self.registration.showNotification(title, {
    body,
    icon,
    badge,
    image,
    data: { ...data, timestamp },
    actions,
    tag,
    renotify,
    requireInteraction,
    silent,
    vibrate,
    timestamp
  });

  event.waitUntil(promise);
});

// ============================================================
// NOTIFICATION CLICK — User tapped the notification
// ============================================================
self.addEventListener('notificationclick', (event) => {
  event.notification.close();

  const { url = '/#/', requestId, action } = event.notification.data || {};

  // Handle action buttons (e.g., "View", "Dismiss")
  if (action === 'dismiss') return;

  // Focus existing window or open new one
  event.waitUntil(
    self.clients.matchAll({ type: 'window', includeUncontrolled: true })
      .then((clients) => {
        // Already open? Focus it and navigate
        for (const client of clients) {
          if (client.url.includes(self.location.origin) && 'focus' in client) {
            return client.focus().then(() => client.navigate(url));
          }
        }
        // Not open? Open new window
        return self.clients.openWindow(url);
      })
  );
});

// ============================================================
// NOTIFICATION CLOSE — User dismissed (swiped away)
// ============================================================
self.addEventListener('notificationclose', (event) => {
  // Optional: track dismissal analytics
  console.log('Notification dismissed:', event.notification.tag);
});

// ============================================================
// MESSAGE — Communication from main app to SW
// ============================================================
self.addEventListener('message', (event) => {
  if (event.data?.type === 'SKIP_WAITING') {
    self.skipWaiting();
  }
});

// ============================================================
// PERIODIC SYNC (optional) — Background sync when online
// ============================================================
self.addEventListener('periodicsync', (event) => {
  if (event.tag === 'sync-notifications') {
    event.waitUntil(syncPendingNotifications());
  }
});

import { createTransport } from 'nodemailer';

interface EmailPayload {
  to: string | string[];
  subject: string;
  text: string;
  html?: string;
}

// Primary: Gmail SMTP
const gmailTransport = createTransport({
  host: 'smtp.gmail.com',
  port: 465,
  secure: true,
  auth: {
    user: 'stariumrafadetergents@gmail.com',
    pass: process.env.GMAIL_APP_PASSWORD
  }
});

// Backup: SendGrid API
const sendgridTransport = createTransport({
  host: 'smtp.sendgrid.net',
  port: 587,
  secure: false,
  auth: {
    user: 'apikey',
    pass: process.env.SENDGRID_API_KEY
  }
});

async function sendWithFallback(payload: EmailPayload) {
  // Try Gmail first
  try {
    await gmailTransport.sendMail({
      from: 'Starium Rafa ERP ',
      to: Array.isArray(payload.to) ? payload.to.join(', ') : payload.to,
      subject: payload.subject,
      text: payload.text,
      html: payload.html
    });
    return { sent: true, via: 'gmail' };
  } catch (gmailError) {
    console.warn('Gmail failed, trying SendGrid:', gmailError.message);
  }

  // Fallback to SendGrid
  try {
    await sendgridTransport.sendMail({
      from: 'Starium Rafa ERP ',
      to: Array.isArray(payload.to) ? payload.to.join(', ') : payload.to,
      subject: payload.subject,
      text: payload.text,
      html: payload.html
    });
    return { sent: true, via: 'sendgrid' };
  } catch (sgError) {
    console.error('Both providers failed:', sgError.message);
    throw new Error(`Email delivery failed: ${sgError.message}`);
  }
}

export { sendWithFallback };

Worker Structure

notification-worker/src/index.ts
// ============================================================
// STARIUM NOTIFICATION WORKER
// Handles: Web Push fan-out, Email queue, In-App write
// Deploy: wrangler deploy
// ============================================================

import { sendWithFallback } from './sendEmail';
import webPush from 'web-push';
import { getFirestore, doc, setDoc, updateDoc, collection, query, where, getDocs } from 'firebase-admin/firestore';
import { initializeApp, cert } from 'firebase-admin/app';

// Initialize Firebase Admin (uses service account from env)
initializeApp({
  credential: cert(JSON.parse(process.env.FIREBASE_SERVICE_ACCOUNT))
});
const adminDb = getFirestore();

// Configure Web Push VAPID
webPush.setVapidDetails(
  process.env.VAPID_SUBJECT || 'mailto:admin@starium.com',
  process.env.VAPID_PUBLIC_KEY,
  process.env.VAPID_PRIVATE_KEY
);

interface Env {
  FIREBASE_SERVICE_ACCOUNT: string;
  VAPID_PUBLIC_KEY: string;
  VAPID_PRIVATE_KEY: string;
  VAPID_SUBJECT: string;
  GMAIL_APP_PASSWORD: string;
  SENDGRID_API_KEY: string;
}

export default {
  async fetch(request, env, ctx): Promise {
    const url = new URL(request.url);

    // CORS
    if (request.method === 'OPTIONS') {
      return new Response(null, { headers: corsHeaders() });
    }

    // Verify JWT (your existing auth)
    const authResult = await verifyAuth(request, env);
    if (!authResult.ok) return Response.json({ error: authResult.error }, { status: 401, headers: corsHeaders() });

    const user = authResult.user;

    if (url.pathname === '/push/subscribe' && request.method === 'POST') {
      return handleSubscribe(request, env, user);
    }
    if (url.pathname === '/push/unsubscribe' && request.method === 'POST') {
      return handleUnsubscribe(request, env, user);
    }
    if (url.pathname === '/notify' && request.method === 'POST') {
      return handleNotify(request, env, user);
    }
    if (url.pathname === '/notify/leave' && request.method === 'POST') {
      return handleLeaveNotify(request, env, user);
    }

    return Response.json({ error: 'Not found' }, { status: 404, headers: corsHeaders() });
  }
};

function corsHeaders() {
  return {
    'Access-Control-Allow-Origin': '*',
    'Access-Control-Allow-Methods': 'GET, POST, OPTIONS',
    'Access-Control-Allow-Headers': 'Content-Type, Authorization',
  };
}

// ============================================================
// SUBSCRIBE — Save user's push subscription
// ============================================================
async function handleSubscribe(request, env, user) {
  const sub = await request.json();
  if (!sub?.endpoint || !sub?.keys?.p256dh || !sub?.keys?.auth) {
    return Response.json({ error: 'Invalid subscription' }, { status: 400, headers: corsHeaders() });
  }

  const subId = hashEndpoint(sub.endpoint);
  await adminDb.collection('push_subscriptions').doc(user.uid).collection('subscriptions').doc(subId).set({
    ...sub,
    userAgent: request.headers.get('user-agent') || '',
    createdAt: new Date(),
    active: true
  });

  return Response.json({ ok: true, subId }, { headers: corsHeaders() });
}

// ============================================================
// UNSUBSCRIBE — Mark inactive (don't delete, audit trail)
// ============================================================
async function handleUnsubscribe(request, env, user) {
  const { endpoint } = await request.json();
  const subId = hashEndpoint(endpoint);
  await adminDb.collection('push_subscriptions').doc(user.uid).collection('subscriptions').doc(subId).update({
    active: false,
    deactivatedAt: new Date()
  });
  return Response.json({ ok: true }, { headers: corsHeaders() });
}

// ============================================================
// NOTIFY — Generic notification fan-out
// ============================================================
async function handleNotify(request, env, user) {
  const { userId, title, body, data, actions, icon, badge, tag, email } = await request.json();

  // Target users: single userId or array, or 'all' for admins
  const targetIds = Array.isArray(userId) ? userId : [userId];

  for (const targetId of targetIds) {
    ctx.waitUntil(fanOutNotification(targetId, { title, body, data, actions, icon, badge, tag, email }, env));
  }

  return Response.json({ ok: true, queued: targetIds.length }, { headers: corsHeaders() });
}

// ============================================================
// LEAVE NOTIFY — Specialized for leave events
// ============================================================
async function handleLeaveNotify(request, env, user) {
  const { requestId, event, employeeId, actorEmail, reason } = await request.json();

  // Load request to get employee + approvers
  const reqSnap = await adminDb.collection('leave_requests').doc(requestId).get();
  if (!reqSnap.exists) return Response.json({ error: 'Request not found' }, { status: 404, headers: corsHeaders() });
  const req = reqSnap.data();

  // Build notification based on event
  const notification = buildLeaveNotification(req, event, actorEmail, reason);

  // Targets: employee + all approvers who signed
  const targets = [req.employeeId, ...(req.approvers || []).map(a => a.uid)];

  for (const targetId of targets) {
    ctx.waitUntil(fanOutNotification(targetId, notification, env));
  }

  return Response.json({ ok: true, targets: targets.length }, { headers: corsHeaders() });
}

// ============================================================
// FAN-OUT — The core logic: Push + In-App + Email
// ============================================================
async function fanOutNotification(userId, notification, env) {
  const { title, body, data, actions, icon = '/rafa-logo.svg', badge = '/badge-72.png', tag = 'starium', email } = notification;

  // 1. WRITE IN-APP NOTIFICATION (always, instant)
  const notifRef = adminDb.collection('notifications').doc();
  await notifRef.set({
    userId,
    title,
    body,
    data,
    read: false,
    archived: false,
    createdAt: new Date(),
    deliveredVia: []
  });

  let deliveredVia = ['inapp'];

  // 2. SEND WEB PUSH (async, best effort)
  try {
    const subsSnap = await adminDb.collection('push_subscriptions').doc(userId).collection('subscriptions')
      .where('active', '==', true)
      .get();

    const pushPromises = subsSnap.docs.map(async (doc) => {
      const sub = doc.data();
      try {
        await webPush.sendNotification(
          { endpoint: sub.endpoint, keys: { p256dh: sub.keys.p256dh, auth: sub.keys.auth } },
          JSON.stringify({ title, body, icon, badge, data, actions, tag }),
          { vapidDetails: { subject: env.VAPID_SUBJECT, publicKey: env.VAPID_PUBLIC_KEY, privateKey: env.VAPID_PRIVATE_KEY } }
        );
        deliveredVia.push('push');
      } catch (err) {
        // If subscription expired (410), mark inactive
        if (err.statusCode === 410) {
          await doc.ref.update({ active: false, deactivatedAt: new Date() });
        }
        console.warn('Push failed:', err.message);
      }
    });
    await Promise.allSettled(pushPromises);
  } catch (err) {
    console.warn('Push lookup failed:', err.message);
  }

  // 3. SEND EMAIL (async, best effort)
  try {
    const userSnap = await adminDb.collection('user_roles').doc(userId).get();
    if (userSnap.exists) {
      const userData = userSnap.data();
      if (userData.email) {
        await sendEmail({
          to: userData.email,
          subject: title,
          text: body,
          html: buildEmailHtml(title, body, data?.url)
        }, env);
        deliveredVia.push('email');
      }
    }
  } catch (err) {
    console.warn('Email failed:', err.message);
  }

  // 4. UPDATE DELIVERY TRACKING
  await notifRef.update({ deliveredVia });
}

function hashEndpoint(endpoint) {
  // Simple hash for doc ID
  let hash = 0;
  for (let i = 0; i < endpoint.length; i++) {
    hash = ((hash << 5) - hash) + endpoint.charCodeAt(i);
    hash |= 0;
  }
  return Math.abs(hash).toString(36);
}

// push_subscriptions — user owns their subs
match /push_subscriptions/{userId}/subscriptions/{subId} {
  allow read: if request.auth != null && request.auth.uid == userId;
  allow create: if request.auth != null && request.auth.uid == userId
    && request.resource.data.keys().hasOnly(['endpoint', 'keys', 'userAgent'])
    && request.resource.data.active == true;
  allow update: if request.auth != null && request.auth.uid == userId
    && request.resource.data.keys().hasOnly(['active', 'deactivatedAt']);
  allow delete: if false; // never delete — audit trail
}

// notifications — user reads own, system writes
match /notifications/{notificationId} {
  allow read: if request.auth != null && request.auth.uid == resource.data.userId;
  allow create: if false; // only Worker (service account) writes
  allow update: if request.auth != null && request.auth.uid == resource.data.userId
    && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['read', 'archived']);
  allow delete: if false;
}

// notification_queue — system only
match /notification_queue/{queueId} {
  allow read, write: if false; // service account only
}

// ============================================================
// PUSH CLIENT — Register, Subscribe, Communicate with Worker
// ============================================================

const WORKER_URL = import.meta.env.VITE_NOTIFICATION_WORKER_URL || 'https://starium-notifications.dammieoptimus.workers.dev';
const VAPID_PUBLIC_KEY = import.meta.env.VITE_VAPID_PUBLIC_KEY;

function urlBase64ToUint8Array(base64String) {
  const padding = '='.repeat((4 - base64String.length % 4) % 4);
  const base64 = (base64String + padding).replace(/-/g, '+').replace(/_/g, '/');
  const rawData = window.atob(base64);
  return Uint8Array.from([...rawData].map(c => c.charCodeAt(0)));
}

export async function registerForPush(user) {
  if (!('serviceWorker' in navigator) || !('PushManager' in window)) {
    console.warn('Push not supported');
    return { ok: false, reason: 'unsupported' };
  }

  try {
    const reg = await navigator.serviceWorker.ready;
    const existingSub = await reg.pushManager.getSubscription();

    if (existingSub) {
      // Already subscribed — send to Worker in case it's new
      await sendSubscriptionToWorker(existingSub, user);
      return { ok: true, subscribed: true, existing: true };
    }

    // Subscribe with VAPID key
    const subscription = await reg.pushManager.subscribe({
      userVisibleOnly: true,
      applicationServerKey: urlBase64ToUint8Array(VAPID_PUBLIC_KEY)
    });

    await sendSubscriptionToWorker(subscription, user);
    return { ok: true, subscribed: true, existing: false };
  } catch (err) {
    if (err.name === 'NotAllowedError') {
      return { ok: false, reason: 'denied' };
    }
    console.error('Push registration failed:', err);
    return { ok: false, reason: 'error', error: err.message };
  }
}

async function sendSubscriptionToWorker(subscription, user) {
  const token = await user.getIdToken();
  await fetch(`${WORKER_URL}/push/subscribe`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` },
    body: JSON.stringify(subscription.toJSON())
  });
}

export async function unregisterFromPush(user) {
  const reg = await navigator.serviceWorker.ready;
  const sub = await reg.pushManager.getSubscription();
  if (!sub) return { ok: true };

  const token = await user.getIdToken();
  await fetch(`${WORKER_URL}/push/unsubscribe`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` },
    body: JSON.stringify({ endpoint: sub.endpoint })
  });

  await sub.unsubscribe();
  return { ok: true };
}

export async function requestNotificationPermission() {
  if (!('Notification' in window)) return 'unsupported';
  const permission = await Notification.requestPermission();
  return permission; // 'granted' | 'denied' | 'default'
}
